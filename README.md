One-sentence absurd invention pitch: a TV remote that buries itself in the sofa the instant the adverts end, purely out of spite, so you must formally negotiate with the cushions before watching anything.

## Run it

```sh
python3 main.py
```

The program writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic, no network, no model calls.
